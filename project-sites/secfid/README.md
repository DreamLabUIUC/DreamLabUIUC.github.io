# SecFid project site

Astro page for *Security–Fidelity Tradeoffs: The Hidden Cost of Prompt Injection Defense*, served at `/secfid/`.

## Develop

```bash
npm install
npm run dev
```

## Build

From the repository root:

```bash
./project-sites/secfid/build.sh
```

Output goes to `secfid/`. Chart data lives in `src/data/results.js`.
